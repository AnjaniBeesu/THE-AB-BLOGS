# AB Blogs

**Random tech shit by Anjani Beesu.**

A personal technical blog built with Next.js and deployed on Vercel.

## Current foundation

- Separate, indexable page for every blog post
- Dynamic `/blog/[slug]` routes
- Per-post metadata and Open Graph data
- BlogPosting JSON-LD structured data
- Generated sitemap and robots.txt
- Responsive desktop ad rail + mobile ad strip placeholder
- Author footer on every article
- Simple content model so new posts can be added without creating new page components
